# Feuille de route

- [x] **Étape 0 — Cadrage** : GDD v0.1, choix du moteur (Godot 4).
- [x] **Étape 1 — Prototype** : boucle idle, 3 rôles, gains hors-ligne, sauvegarde.
- [x] **V1 jouable** : expéditions (astéroïdes, étoile, planète), améliorations du vaisseau, hors-ligne, fond d'étoiles.
- [x] **V1 RPG + 2D/3D** : 9 héros (classes, raretés, niveaux, étoiles), recrutement aléatoire, escouades, combats automatiques, scène 3D des destinations ([détails](V1.md)).
- [x] **Combats animés** : coups, barres de vie, dégâts, bandeau de résultat, rejouable.
- [x] **V2 — Le Capitaine** (inspiré de Mini Legion: Rise) : le joueur est un personnage personnalisable, l'équipage devient des objets à des postes, équipement évolutif avec butin, personnages « chibi » ([détails](V2.md)).
- [x] **V2.1 — Équipage AFK + loot RPG** : production même hors ligne, rendement et durée hors ligne, 6 emplacements, 5 raretés, bonus aléatoires, recyclage auto.
- [x] **Style visuel R2** : thème verre/cyan, polices, icônes SVG, cartes d'équipement à cadre de rareté, combat et rapport hors ligne restylés ([STYLE.md](STYLE.md)).
- [x] **Socle de durée** : Labo (recherches en temps réel, file, accélération), plafonds de niveau relevés par des académies, économie recalibrée, simulateur à 4 profils ([détails](AFK.md)).
- [x] **Refonte « deux jeux »** : plus de plafonds de niveau, l'AFK est l'équipage seul, le Capitaine gagne son XP par les **anomalies** (contenu actif), et le niveau d'AFK fait monter la qualité du butin du Capitaine ([détails](AFK.md)).
- [ ] **V2-C — Anomalies (suite : boss de secteur, tour d'épreuves)** (donjons solo, meilleur temps), **boss de secteur**, **tour d'épreuves**.
- [ ] **V2-D — Campagne** : chapitres narratifs, un par secteur.
- [ ] Vrais assets graphiques et sons.
- [ ] **Étape 2 — Univers** : fond spatial parallaxe, carte des secteurs, premiers boss.
- [ ] **Étape 2b — Exploration** : système d'expéditions (destination + équipage + durée), puis les 3 types :
  - [ ] Astéroïdes (le plus simple : minage automatique)
  - [ ] Étoiles (collecte d'énergie, bouclier)
  - [ ] Planètes (atterrissage, étapes d'expédition, événements)
- [ ] **Étape 3 — Profondeur** : raretés, formation en slots, équipements.
- [ ] **Étape 4 — Rétention** : prestige, quêtes quotidiennes, notifications.
- [ ] **Étape 5 — Équilibrage** : tableur des courbes de progression.
- [ ] **Étape 6 — Android** : export, icône, tests fermés, Google Play (25 $ unique).
- [ ] **Étape 7 — Monétisation** : pubs récompensées, achats intégrés.
