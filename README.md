# Altopia

RPG idle de combat automatique, space opera, pour mobile (Android) : on collectionne et fait progresser des héros, leurs escouades combattent seules, la progression continue hors ligne. Inspirations : Top Heroes, Mini Legion.

Le projet a été **repris de zéro**. L'ancienne version (jeu, personnages 3D, tutoriel, outils) est conservée intacte sur la branche `archive/altopia-v1`.

- Conception : [docs/GDD.md](docs/GDD.md)
- Moteur : Godot 4.3 (rendu GL Compatibility). `tools/setup_godot.sh` télécharge le binaire.
