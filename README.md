# Altopia

Jeu Android de type **RPG idle / AFK** dans l'espace : on compose un équipage,
on l'envoie explorer des secteurs inconnus, et l'exploration continue même
quand le joueur est hors-ligne.

- Moteur : [Godot 4](https://godotengine.org/) (GDScript)
- Plateforme cible : Android (portrait)
- Direction : 2D avec effets de profondeur (parallaxe), évolutive vers la 3D
