# Modèles d'astronautes à intégrer

Déposer ici, un dossier par modèle : `art_src/astronautes/<nom>/`
- le modèle (`.glb`, `.gltf` + ses fichiers, ou `.fbx`) et ses textures ;
- un fichier `LICENCE.txt` : nom du modèle, auteur, lien Sketchfab, licence affichée sur la page (CC0, CC-BY...).

Règles de choix : modèle téléchargeable, licence CC0 ou CC-BY (pas de NC ni ND), de préférence riggé et animé, low poly.
Le dossier est ignoré par Godot (`.gdignore`). L'intégration (recoloration par personnage, animations, export Godot, portraits) se fait avec Blender.
